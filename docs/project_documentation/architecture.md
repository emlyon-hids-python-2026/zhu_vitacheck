# Architecture

## Overview

```text
                 ┌────────────────────────── same analysis, 4 ways to deliver it ───────────────────────────┐
                 │                                                                                         │
 data/*.csv ───> 1 notebook ─────> 2 script with cells ─────> 3 script with functions ─────> 4 Streamlit app
                 (explore)          (same code, in a .py)      (reusable functions)           (user uploads,
                                                                                               filters, export)
```

Each version is a step in the progression of the course: first understand the steps one by one in a
notebook, then make them a script, then structure the script in functions, then give it a user interface.
The four versions give **the same numbers** (see [results](results.md)).

## The pipeline

| Step | Version 1-2 (cells) | Version 3 (`scripts/03_diabetes_functions.py`) | Version 4 (`app/app.py`) |
|---|---|---|---|
| Ingestion | `pd.read_csv` ×3 | `load_data(data_dir)` | `load_data(part_files, mapping_file)` |
| Consolidation | `pd.concat` + `merge` + `assert` | `consolidate(...)` | `consolidate(parts, gender_mapping)` |
| Technical Q1 | `pd.DataFrame({...})` | `compute_shapes(datasets)` | `compute_shapes(datasets)` |
| Business Q1-Q8 | one cell per question | `answer_business_questions(df)` | `answer_business_questions(df)` |
| Question/answer table | dictionary → DataFrame | dictionary → DataFrame in `main()` | `build_insights_table(...)` |
| Graphs | matplotlib, `savefig` | `make_graphs(df, output_dir)` | `make_graphs` (export) + `make_interactive_charts` (display) |
| Export | `pd.ExcelWriter` to disk | `export_analysis(...)` | `to_excel_bytes`, `to_csv_bytes`, `graphs_to_zip_bytes` (download) |
| Entry point | run the cells | `main()` | `main()` called by Streamlit |

## Design decisions

| Decision | Reason |
|---|---|
| **Dictionary first, then DataFrame** | Requested by the brief: build `{question: answer}` and convert with `pd.DataFrame(list(d.items()), columns=[...])`. Same for the shapes table |
| **Left merge + checks** | A left merge cannot lose patients; the two checks catch a bad mapping instead of hiding it |
| **Duplicates are kept** | No patient identifier: identical lines can be different patients ([data.md](data.md#duplicates)) |
| **Prevalence = mean of `diabetes`** | `diabetes` is 0/1, so the mean is the share of diabetic patients |
| **One Excel file, one sheet per table** | The prevention teams copy the tables into their presentations |
| **Version 4: one file `app/app.py`** | Functions and UI together, in sections, easy to read for a course project. The functions stay independent of Streamlit, so they can be tested alone |
| **Version 4: user uploads only** | The app does not depend on the local `data/` folder: anyone can use it with their own files |
| **Version 4: any number of parts** | The centres may send 2, 3 or 4 files; the pipeline concatenates whatever is loaded |
| **Two chart sets in version 4** | Altair (interactive, hover) for the screen; matplotlib for the PNG/Excel export, because exporting Altair images needs an extra package (`vl-convert`) |
| **Fixed colours** | Pink / blue for gender, teal / orange for non-diabetic / diabetic: the same meaning on every graph |
| **Pandas 3 `str` dtype** | The text columns have the `str` dtype: `describe(include=["str"])` selects them, and mixed-type frames must be cast before display (Arrow limitation) |
